# v0.13.0

Added:

- Linear Sync.
- Синхронизация задач с Linear.
- `./pmem tasks linear status`, `export`, and `import`.
- Optional `integrations.linear` config for a local JSON bridge.

Updated:

- Imported Linear issues become Markdown tasks under `.agents/tasks/linear/`.
- Imported tasks are re-indexed automatically so other agents can find them through `tasks check` and search.

Removed:

- Nothing.

Better than v0.12.0:

- Linear can participate in multi-chat task coordination without becoming a required dependency.
- Local task files remain the fallback and source of truth when Linear is not configured.
