# v0.14.0

Added:

- Real File Watcher.
- Настоящий локальный наблюдатель файлов.
- `./pmem watch --serve` for explicit long-running local polling.

Updated:

- `./pmem watch` runs one safe check by default.
- `--interval` and `--max-runs` still support bounded watcher runs.
- Watch checks use hash freshness and trigger local changed indexing when files are stale.

Removed:

- Nothing.

Better than v0.13.0:

- Agents can keep memory fresh locally during a task.
- Accidental `./pmem watch` no longer starts an unbounded process.
