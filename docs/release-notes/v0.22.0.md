# v0.22.0

Multi-chat Write Concurrency.

Added:

- SQLite `busy_timeout` on runtime connections.
- Managed write lock with metadata, TTL, and stale cleanup.
- `pmem lock status`, `pmem lock clear`.
- Local write queue: `pmem queue list`, `pmem queue drain`, `pmem queue clear`.
- Optional Qdrant server URL through `vector.url`.

Upgrade behavior:

- Existing `.project-memory/graph.sqlite` is preserved.
- Existing `.project-memory/qdrant/` is preserved.
- Existing knowledge, rationale, Human exports, logs, reports, and evals are preserved.
- New runtime/cache files stay under `.project-memory/runtime/` and are ignored by Git.
