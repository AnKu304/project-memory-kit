# v0.8.0

Added:

- npm/npx distribution through `package.json` and `npm/bin/pmem.js`.
- Install profiles: `Codex`, `Claude`, and `Multi-agent`.
- Claude Code files: `CLAUDE.md`, `.claude/rules/`, `.claude/skills/`, `.claude/commands/`.
- Multi-agent files: `.agents/roles/` and `.claude/agents/`.
- `./pmem audit --secrets`.
- `./pmem optimize`.
- `./pmem mcp-config`.
- GitHub Actions CI.
- Code bloat guard tests for oversized Python functions and files.

Updated:

- Upgrade can preserve the installed profile with `--agent auto`.
- Config schema moved to `6`.
- Version fields are synchronized across Python, runtime, and npm package metadata.

Removed:

- Nothing.

Better than v0.7.0:

- Installation works through `pipx` or `npx`.
- Claude Code and multi-agent projects no longer need hand-built instruction folders.
- Local verification is stronger before sending large context to an agent.
