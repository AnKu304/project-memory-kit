# v0.22.2

Pruned Traversal Fix.

Added:

- Pruned project walker for index freshness, changed/full indexing, and secret audit.
- Generated ignore defaults for `.playwright-cli/`, `.playwright-mcp/`, `.turbo/`, and `coverage/`.
- Runtime normalization that adds these generated ignores for older config files.

Updated:

- `pmem status`, `pmem index`, `pmem context`, and `pmem audit --secrets` no longer rely on unpruned `root.rglob("*")`.
- Ignored heavy directories are skipped before descent instead of filtered after traversal.
- Agent instructions now avoid unconditional preflight indexing. `./pmem index --mode changed` runs before editing only when freshness affects the task or retrieved context looks incomplete, and remains mandatory after meaningful edits.

Upgrade behavior:

- Existing `.project-memory/` data is preserved.
- Existing config files are not destructively rewritten.
- Old config versions receive safe generated-ignore defaults at runtime.
