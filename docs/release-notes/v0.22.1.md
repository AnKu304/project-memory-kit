# v0.22.1

Contention Fix.

Added:

- Guarded embedded Qdrant access with `.project-memory/runtime/qdrant.lock`.
- Regression tests for watcher contention, busy auto-index, and Qdrant busy fallback.

Updated:

- `watch --serve` no longer holds the global write lock while sleeping.
- Auto-index skips immediately when `write.lock` is active.
- Default SQLite busy timeout is `3000ms`.
- Default write-lock timeout is `5s`.
- Default embedded Qdrant lock timeout is `2s`.
- `vector.backend: auto` falls back to SQLite/BM25 when embedded Qdrant is busy.

Upgrade behavior:

- Existing `.project-memory/` data is preserved.
- Existing config files do not need destructive rewrites; new defaults are merged by runtime.
- Projects that need heavy parallel vector access can still set `vector.url` to a local Qdrant server.
