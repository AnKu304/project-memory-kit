# v0.10.0

Added:

- npm package smoke script: `npm run smoke`.
- npm package tarball validation: `npm run pack:check`.
- npm `prepack` smoke check.
- npm distribution guide under `docs/npm.md`.
- CI steps for npm smoke and package contents.

Updated:

- npm package version moved to `0.10.0`.
- npm `files` list now includes only required source, runtime, templates, docs, and wrapper files.
- Node wrapper now requires Python 3.11+ before running the CLI.
- Package metadata now includes `bugs`, `type: commonjs`, and public scoped publish config.

Removed:

- Generated Python cache files are excluded from the npm package.

Better than v0.9.0:

- The npm package is much closer to publish-ready.
- `npm pack` output is checked automatically instead of by manual inspection.
- Users get a clearer failure when Python is missing or too old.
