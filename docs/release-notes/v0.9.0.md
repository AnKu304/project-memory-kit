# v0.9.0

Added:

- `.agents/tasks/` templates for user tasks and agent-to-agent handoffs.
- `./pmem tasks check` and `./pmem tasks list`.
- MCP tool `pmem_tasks`.
- `./pmem mcp-config --client claude --write` for `.mcp.json`.
- Secret audit checks for JWT-like tokens and high-entropy assigned values.
- Secret audit allowlist support in `.project-memory/config.yaml`.
- JS/TS workspace/package alias resolution.
- Next.js app route metadata during indexing.
- Eval fixture templates under `.project-memory/evals/`.
- Claude `.claude/settings.json` security defaults.
- Version/config/documentation quality guard tests.

Updated:

- Upgrade preserves memory while adding Codex, Claude, or Multi-agent profiles.
- Installer metadata records all installed agent profiles.
- Multi-agent profile includes shared rules and task templates.
- `./pmem watch` can run a bounded loop with `--interval` and `--max-runs`.
- Config schema moved to `7`.

Removed:

- Nothing.

Better than v0.8.0:

- JS/TS/Next projects produce more useful dependency context.
- Multi-chat work can coordinate through local task files and MCP.
- Claude MCP setup can be written automatically.
- Secret audit is stronger and easier to tune.
