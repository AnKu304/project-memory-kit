# v0.12.0-v0.20.0 Improvement Checklist

Purpose: implement the next nine project-memory improvements as separate, testable releases.

Rule for this checklist:

- each major item is released as its own version;
- each task and subtask has an explicit status;
- each task gets focused tests before it is marked `done`;
- each release updates `CHANGELOG.md`, release notes, docs where needed, and version fields;
- after all nine releases, Russian and English descriptions are shortened, normalized, and humanized.

## Status Legend

- `done`: implemented, tested, released.
- `in_progress`: currently being implemented or tested.
- `pending`: not started yet.
