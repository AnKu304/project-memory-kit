# v0.21.0 Depth Improvements Checklist

Purpose: improve project-memory quality in depth: better context, ranking, graph accuracy, local evidence, task gates, and provenance.

Rule for this checklist:

- each item has explicit status;
- each implementation item gets focused tests before it is marked `done`;
- release updates `CHANGELOG.md`, release notes, README files, and version fields;
- keep the project local-first and dependency-light.

## Status Legend

- `done`: implemented, tested, released.
- `in_progress`: currently being implemented or tested.
- `pending`: not started yet.
